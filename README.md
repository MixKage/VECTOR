# Интегрированная платформа трудоустройства для ОЭЗ

Мы создали **интегрированную платформу для трудоустройства в Особой Экономической Зоне (ОЭЗ)**,
которая объединяет соискателей, работодателей и администрацию ОЭЗ.  
Платформа позволяет компаниям быстро публиковать вакансии, соискателям — удобно находить работу,
а администрации — в реальном времени отслеживать ключевые метрики рынка труда и эффективность программ трудоустройства.

---

## 🧠 Стек технологий

**Frontend:** TypeScript, JavaScript, HTML, CSS, React, Hero UI  
**Backend:** Python, PostgreSQL, Redis, Docker Compose, Alembic, Pydantic, SQLAlchemy  

**Особенности архитектуры:**

- Многоуровневая структура с разделением интерфейсов (HR / Соискатель / Администратор)
- REST API для интеграции и взаимодействия сервисов
- Система аналитики в реальном времени
- Умные фильтры подбора кандидатов
- Парсер табличных данных (CSV, XLSX)
- Возможность встраивания в существующие решения
- Интеграция с внешними CRM-системами

---

## 💎 Уникальность решения

Единственная в России **интегрированная платформа трудоустройства**, специально разработанная
для нужд **Особых Экономических Зон**, обеспечивающая **полный цикл** — от поиска работы
до аналитики эффективности программ занятости.

В отличие от универсальных решений:

| Платформа | Особенности |
|------------|--------------|
| **HeadHunter** | Массовый рынок, нет специализации под ОЭЗ |
| **Avito Работа** | Региональные вакансии, отсутствует аналитика для администраций |
| **LinkedIn** | Международная сеть, без кастомизации под российские ОЭЗ |

---

## 🚀 Результат

Платформа оптимизирует взаимодействие между всеми участниками рынка труда в ОЭЗ,
повышает эффективность трудоустройства и обеспечивает прозрачную аналитику для управленцев.
